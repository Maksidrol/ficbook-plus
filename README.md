# Фикбук+

Неофициальный Android-клиент для [ficbook.net](https://ficbook.net) с тёмной темой Material 3.

## Что умеет

- Удобная читалка: настройки шрифта, размера, межстрочного интервала
- Два режима чтения — прокрутка и постраничный
- Навигация жестами между главами
- Запоминание позиции чтения по каждой главе
- Карточки произведений с обложкой, главами, комментариями, коллекциями
- Принудительная тёмная тема, убрана реклама и лишние элементы сайта

## Технически

Android-приложение на Kotlin + GeckoView (Firefox). Стили и логика читалки реализованы как MV2 WebExtension, которое инжектируется в страницы ficbook.net.

Читалка основана на userscript [Ficbook Material 3 Dark Reader](https://greasyfork.org/ru/scripts/598198-ficbook-material-3-dark-reader) от Qeeew.

## Требования

- Android 8.0+
- Архитектуры: arm64-v8a, armeabi-v7a

## Сборка

```bash
./gradlew assembleDebug
```

> APK подписан debug-ключом.
